Webpack-dev-server

Зміни додані тільки в файл package.json

В терміналі прописати npm run serve або npx webpack-dev-server --mode development --open

Попередньо було прописано в терміналі команда встановлення плагіну npm install webpack-dev-server --save-dev

Данний плагін автооновлює сторінку при змінні коду

Щоб вийти в терміналі з режиму слідкування за файлами, потрібно ввести комбінацію клавіш ctrl + c двічі, або з першого разу підтвердити написавши y і Enter
